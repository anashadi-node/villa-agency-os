Internal · Untuk Karyawan

🖥️ Dashboard Karyawan/Admin

Kode: src/dashboard.py (3.144 baris) — satu dashboard dengan 13 halaman berbasis peran (RBAC 6 peran: reservation, operations, finance, owner, auditor, gm). Command Center = halaman utama admin. Ada MFA wajib untuk owner/finance/gm.

Cara lihat:
python3 src/dashboard.py --db data/villa.db → buka http://127.0.0.1:8080

⚠️ Koreksi penting soal port 8788: service anantara-dashboard.service yang berjalan di port 8788 itu milik proyek Anantara Sakti (dashboard trading), bukan Villa Agency OS. Dashboard villa saat ini tidak berjalan sebagai service — harus dijalankan manual dengan perintah di atas, atau dipasang sebagai systemd unit sesuai docs/DEPLOYMENT.md (belum dilakukan).
